## 三种使用路线

**路线一：系统复习（2~3 小时）**
`00 总纲` 通读 → 四个分册按 01→04 顺序读，每册结尾的「一页纸背诵版」当作自测清单，盖住上半页只看背诵版，说出不来的地方回去看正文。

**路线二：快速恢复手感（30 分钟）**
只读 `速查卡`。哪一行看不懂或想不起细节，顺着该行指到的分册节号跳过去。

**路线三：带问题来（不定）**
先在 `速查-反查` 里按症状分类找到定位，到对应分册节看机制原理，需要命令/代码细节再跳回原文专栏篇目（分册每节末尾和反查表都标了"专栏X·XX"）。
